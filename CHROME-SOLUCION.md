## 🛠️ **SOLUCIONES PARA PROBLEMAS EN CHROME**

### **❌ Problema: "Esta página no se puede mostrar"**
**✅ Solución:**
```
1. Verificar que el servidor esté ejecutándose
2. Usar: http://localhost:8080/login.html (exacto)
3. Si no funciona, usar: http://192.168.1.94:8080/login.html
```

### **❌ Problema: "No se puede conectar"**
**✅ Solución:**
```
1. Reiniciar el servidor:
   - Presionar Ctrl+C en la terminal
   - Ejecutar: python server.py
   
2. Verificar firewall de Windows
3. Usar navegador incógnito (Ctrl+Shift+N)
```

### **❌ Problema: "Páginas en blanco"**
**✅ Solución:**
```
1. Limpiar caché de Chrome:
   - Presionar: Ctrl+Shift+Delete
   - Seleccionar: "Todo el tiempo"
   - Borrar datos
   
2. Desactivar extensiones:
   - Modo incógnito: Ctrl+Shift+N
```

### **❌ Problema: "JavaScript no funciona"**
**✅ Solución:**
```
1. Verificar que JavaScript esté habilitado:
   - Configuración → Privacidad y seguridad → Configuración del sitio → JavaScript
   
2. Agregar excepción para localhost:
   - Configuración → Privacidad y seguridad → Configuración del sitio
   - Agregar localhost como sitio permitido
```

## 🔧 **SOLUCIONES PARA CHROME**

### **❌ Si Chrome no carga las páginas:**
```
1. Verificar que el servidor esté ejecutándose
2. Usar modo incógnito: Ctrl+Shift+N
3. Limpiar caché: Ctrl+Shift+Delete
4. Probar con URLs alternativas (192.168.1.94)
```

### **❌ Si JavaScript no funciona:**
```
1. Chrome → Configuración → Privacidad y seguridad
2. Configuración del sitio → JavaScript
3. Verificar que esté "Permitido"
4. Agregar localhost como excepción
```

### **❌ Si aparecen errores de conexión:**
```
1. Reiniciar el servidor (Ctrl+C, luego python server.py)
2. Verificar firewall de Windows
3. Probar con otro puerto si es necesario
```

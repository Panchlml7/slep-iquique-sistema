📞 ¿Problemas de Acceso?

  1. Verifica tu conexión a internet - Intenta abrir otros sitios web
  2. Cambia de navegador - Prueba Chrome, Firefox, Safari o Edge
  3. Borra caché y cookies - Usa el botón "Limpiar Caché" arriba
  4. Verifica la URL - Copia exactamente una de las URLs de arriba
  5. Intenta desde otro dispositivo - Prueba desde otra computadora o celular
  6. Verifica restricciones de red - Pregunta si tu organización bloquea GitHub

📱 Acceso desde iPhone/iPad

  1. Abre Safari o Chrome
  2. Toca en la barra de direcciones
  3. Escribe exactamente: https://panchlml7.github.io/slep-iquique-sistema/
  4. Presiona Ir o Enter
  5. Si aparece un error, verifica tu conexión WiFi o datos móviles

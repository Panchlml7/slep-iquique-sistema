# SLEP Iquique Sistema

Este repositorio contiene el sistema de gestión SLEP Iquique. Aquí encontrarás los archivos principales del sistema, scripts de inicio y recursos web.

## Instrucciones rápidas

- Para iniciar el sistema, utiliza los archivos `.bat` según tu necesidad.
- El archivo principal para la web es `SISTEMA-SLEP-COMPLETO.html` (puedes renombrarlo a `index.html` para GitHub Pages).
- Los recursos adicionales están en las carpetas `css/`, `js/`, `documentos/`, `public/` y `server/`.

## Publicar en GitHub Pages

1. Renombra `SISTEMA-SLEP-COMPLETO.html` a `index.html`.
2. Ve a la configuración del repositorio en GitHub.
3. Activa GitHub Pages desde la rama `main` y la carpeta raíz (`/`).
4. Accede a la URL que te entrega GitHub Pages.

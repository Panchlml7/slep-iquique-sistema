## 📖 **Descripción del Proyecto**

**SLEP IQUIQUE** es un sistema integral de gestión educativa desarrollado para el Servicio Local de Educación Pública de Iquique. Proporciona herramientas completas para la administración de usuarios, gestión de documentos pedagógicos y control de asistencia.

## ✨ **Características Principales**

### 🔐 **Sistema de Autenticación Avanzado**
- **Login seguro** con múltiples niveles de acceso
- **Gestión de usuarios** con estados (pendiente, aprobado, rechazado)
- **Control de permisos** por roles (usuario, admin, super admin)
- **Recuperación de contraseñas** y gestión de sesiones

### 👥 **Gestión de Usuarios Completa**
- **Modal de detalles** con información completa de usuarios
- **Funcionalidad de contraseñas** (mostrar/ocultar)
- **Sistema de búsqueda avanzado** con filtros múltiples
- **Aprobación/rechazo** de solicitudes de registro
- **Promoción de usuarios** a administradores

### 📋 **Gestión de Documentos Pedagógicos**
- **Formularios dinámicos** para acompañamiento de visitas
- **Sistema de pestañas** para organización de datos
- **Búsqueda inteligente** por múltiples criterios
- **Almacenamiento local** de documentos
- **Estadísticas en tiempo real**

### 📊 **Módulo de Asistencia**
- **Subida de archivos Excel** para datos de asistencia
- **Procesamiento automático** de información
- **Visualización de estadísticas** de asistencia
- **Filtros por fecha y establecimiento**

## 🎯 **Cómo Usar el Sistema**

### **1. Acceso Inicial**
```bash
1. Visita: https://panchlml7.github.io/slep-iquique-sistema/
2. Usa las credenciales proporcionadas
3. Explora los diferentes módulos
```

### **2. Gestión de Usuarios**
```bash
1. Ir a "Administración" → "Gestión de Usuarios"
2. Usar la búsqueda para encontrar usuarios específicos
3. Hacer clic en "Ver Detalles" para información completa
4. Usar toggle de contraseña para mostrar/ocultar
```

### **3. Documentos Pedagógicos**
```bash
1. Ir a "Documentos" desde el menú principal
2. Completar formulario en pestañas organizadas
3. Buscar documentos existentes con filtros
4. Ver estadísticas en tiempo real
```

### **4. Control de Asistencia**
```bash
1. Acceder al módulo "Asistencia"
2. Subir archivo Excel con datos
3. Procesar y visualizar automáticamente
4. Usar filtros para análisis específicos
```
